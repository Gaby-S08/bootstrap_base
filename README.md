## 📌 Sobre o Trabalho

Este projeto tem como objetivo explorar o uso do **Bootstrap**, um framework front-end que facilita a criação de interfaces modernas, responsivas e organizadas.

Durante o desenvolvimento, foram aplicados conceitos fundamentais de design responsivo e reutilização de componentes.

---

## 🎯 Objetivos

- Utilizar o framework Bootstrap na prática  
- Criar um layout moderno e responsivo  
- Aplicar componentes prontos (cards, navbar, grid, etc.)  
- Melhorar a organização visual de páginas web
